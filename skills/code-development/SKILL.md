# Zmiana kodu i test

- Ustal oczekiwane zachowanie i zachowaj istniejące kontrakty projektu.
- Przygotuj spójną poprawkę o zakresie wynikającym z zadania, bez niepowiązanego refaktoru.
- Dodaj test konkretnej regresji lub ryzyka. Nie kopiuj implementacji do testu.
- Opisz pełną zmianę, sposób weryfikacji i pozostałe ograniczenia.
- Potwierdzaj zapis i wyniki testów wyłącznie na podstawie pomiarów kontrolera. Propozycja nie oznacza wykonania.
- Zachowaj wymagany diff i zatwierdzenie zapisu. Skill nie przyznaje narzędzi, dostępu do plików ani zgody na ich zmianę.
